## Описание задачи
Датасет US Perm Visas содержит данные о заявках на Permanent Labor Certifications (PERM) для виз в США. Задача — классификация: предсказать, будет ли заявка одобрена (Certified) или отклонена (Denied) на основе признаков, таких как профессия, зарплата, образование и т.д. Это задача бинарной классификации с несбалансированными классами (больше одобренных заявок).

Анализ включает предобработку данных, визуализацию, обучение моделей (KNN, Random Forest, Logistic Regression) и сравнение результатов. Цель — достичь высокой точности на тестовой выборке, учитывая несбалансированность.

## Структура проекта
- `analysis.py`: Основной скрипт с полным анализом.
- `requirements.txt`: Зависимости.
- Данные: Скачайте `us_perm_visas.csv` с Kaggle и поместите в корень.

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `python analysis.py`

## Результаты
- KNN с k=5: Точность на тесте ~0.08.
- Random Forest: Лучшая точность ~0.89.
- Logistic Regression: Точность ~0.47.

Несбалансированность решена SMOTE. 
Коррелированные переменные не исключены, так как их влияние минимально.

## Выводы
Не все модели хорошо справляются с задачей. Random Forest — лучший выбор из-за обработки категориальных признаков и устойчивости к шуму.
